# Моя учёба — приложение для Telegram и телефона

Работает без интернета после первого открытия. Свои конспекты хранятся на телефоне.
Материал от Claude лежит в `content/library.json`.

## Как выложить (один раз)
1. Создай бесплатный аккаунт на github.com.
2. Создай репозиторий (New repository), назови, например, `uchyoba`, тип Public.
3. В репозитории: Add file → Upload files, перетащи ВСЕ файлы и папку `content` из этого архива, нажми Commit.
4. Settings → Pages → Source: Deploy from a branch → Branch: `main`, папка `/ (root)` → Save.
   Через минуту появится адрес вида `https://ТВОЙ-ЛОГИН.github.io/uchyoba/`.
5. Telegram: напиши @BotFather → `/newbot` (или выбери существующего бота) → `/setmenubutton` →
   выбери бота → вставь адрес из шага 4 → название кнопки «Учёба».
6. Открой бота, нажми кнопку «Учёба» один раз с интернетом: приложение сохранится в кэш.
   Дальше оно открывается без интернета.

## Надёжный офлайн
Открой тот же адрес в Chrome на телефоне → меню → «Добавить на главный экран».
Так приложение живёт отдельной иконкой и офлайн-кэш надёжнее, чем внутри Telegram.

## Обновление материала
Редактируется `content/library.json` (параметр `rev` нужно увеличивать при каждом обновлении).
Это делает Claude, когда репозиторий подключён к чату.
